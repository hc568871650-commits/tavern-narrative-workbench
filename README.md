# 叙事工作台 · 0.4.0 预览版

为 SillyTavern 聊天提供人物、任务、状态、背包与快捷动作界面，并提供可关闭的游玩页美化。无需编译，使用酒馆的「安装扩展」粘贴 Git 仓库链接安装。

> 本项目是前端扩展，不是 APK，也不是独立酒馆。业务数据由 **shujuku（龙血玄黄·数据库）** 保存；工作台负责展示、配置映射、检查和动作草稿。安装工作台不会自动安装数据库，也不会自动把任意角色卡变成带背包的游戏。

本仓库提供 **0.4.0 预览版**，已完成真实 GitHub 匿名安装与 0.3.1 → 0.4.0 原生更新验证。更新内容见 [更新说明](CHANGELOG.md)，详细范围见 [验收记录](INSTALL-VERIFICATION.md)。

## 链接安装

适用于提供第三方扩展安装功能的 SillyTavern 实例。电脑浏览器和手机浏览器使用同一个安装入口；若手机连接的是电脑/服务器上的酒馆，扩展装在该酒馆实例中。

1. 打开酒馆的 **扩展 → 安装扩展**，先粘贴数据库仓库链接：
   ```text
   https://github.com/AlbusKen/shujuku
   ```
2. 安装完成后刷新酒馆，再次打开「安装扩展」，粘贴**本仓库首页链接**：
   ```text
   https://github.com/hc568871650-commits/tavern-narrative-workbench
   ```
   上面是本项目的安装地址。不要使用 README 页面、`tree/main` 子目录、Release ZIP 或 `raw` 文件链接。
3. 刷新页面，在「管理扩展」确认数据库和叙事工作台均已启用。正常加载后，聊天页面出现「叙事工作台」入口和场景工具栏。
4. 打开一张角色卡的聊天，按下方步骤配置。只安装扩展，还不会自动出现这张卡的物品和任务。

当前没有上架酒馆内置扩展目录；使用「安装扩展」粘贴 Git 地址即可。工作台不要求酒馆助手，但你所用角色卡可能有自己的依赖。

## 第一次体验

建议先用新建测试聊天，不要直接给已有存档导入样例表。0.4.0 已在数据库根入口上完成首次样例初始化、历史帧校验与磁盘回读。详见 [验收记录](INSTALL-VERIFICATION.md)。

1. 进入一张单角色卡的新聊天，打开「工作台」→「卡片适配」。
2. 点击「操作栏样例」，检查配置后点击「应用到本聊天」。
3. 仅在只有开场消息、没有已有数据库帧和业务数据的空白聊天，点击「为空白聊天建立样例表」，阅读确认内容后继续。
4. 关闭工作台，在聊天工具栏查看人物、任务、状态、背包等内容；打开一个动作并加入草稿。
5. 草稿会追加到原输入框，保留已有文字，**不会自动发送、扣库存或调用模型**。由你检查后决定是否发送。

样例初始化会写入当前测试聊天的表结构和初值。自定义角色卡应在数据库编辑器中建立自己的表，再调整适配配置中的表名、字段、主键、显示筛选和动作。适配配置按聊天保存；其他聊天需分别配置或导入。

`examples/journey.json` 与 `journey.tables.json` 是操作栏样例；`academy` 与 `starship` 是其他题材样例。全部是演示数据，不是正式角色卡，也不包含模型服务或预设。

## 给世界卡里的角色绑定图片

1. 先打开世界卡聊天，应用人物表适配，等状态显示「当前状态」。
2. 点击聊天顶部或工作台里的「人物图片」，选择周宁、陈岚等人物。
3. 点击「选择头像或立绘」，选择 PNG/JPEG/WebP；单图不超过 3 MiB。可选择铺满画框或显示完整图片，并调整水平、垂直焦点。
4. 填写**公开简介**，预览后点击「保存此人物」。只有保存时才上传；完成提示会核对酒馆服务器中的角色卡配置。
5. 侧栏通过「侧栏人物」切换人物，人物列表与详情使用同一图片。没有图片或资源丢失时显示首字占位。

图片绑定与公开简介存于当前世界卡的扩展元数据，同卡各聊天可复用；位置、关系、物品等业务状态仍归各自聊天。群聊暂不支持图片管理。人物表的主键建议用稳定的「角色编号」，姓名另映射为 titleField；演示样例仍用姓名为主键，因此演示人物改名后需重新绑定。

绑定标识为 `[实体ID,人物主键]`。管理界面可展开查看。作者可以提前制作和导入图片包；导入不表示人物已经在剧情中出现，普通游玩界面只展示当前适配筛选后的人物。完整人物设定和秘密不要放入公开简介。

**分享或换手机：**同一酒馆实例的手机浏览器可读取其图片。迁移到另一酒馆时，点击「导出含图资源包」，在目标卡「导入资源包」中预览新增/替换人数，再确认合并。总包不超过 15 MiB、最多 100 人；人物标识必须与目标适配匹配。只导出角色卡会带图片路径，不保证带外部图片文件，因此分享时应同时带资源包。

当前只接受上传到酒馆本地的图片和资源包中的 PNG/JPEG/WebP，不接受任意外部图片 URL。解绑不删除物理图片文件；中断上传可能留下未绑定文件，由用户另行整理。多个设备同时编辑同一图片库不提供原子合并，发现配置变化会尽量阻止覆盖，应重新加载核对。

## 界面与手机使用

- 大正文区保留酒馆原生输入框；宽屏有侧栏，窄屏收起侧栏，详情通过弹层查看。
- 点击「原生界面」可关闭游玩页美化；人物、背包与选项列表新增关键词搜索。
- 宽屏侧栏可切换人物，并显示经过可见性筛选的相邻消息字段变化；这不等于所有后台任务均已结算。
- 手机浏览器访问正在运行的酒馆即可使用已安装的扩展。上传 GitHub 只提供安装来源，不会自动托管酒馆服务或同步聊天。
- 若手机应用没有第三方扩展入口，不能据此认定可以安装本项目。原生手机壳、Tauri WebView、软键盘遮挡等仍需在实际设备上确认。

## 数据与支持边界

- 工作台不复制一份可写业务数据库；状态来自 shujuku。适配配置存于当前聊天的 `chat_metadata.narrativeWorkbenchV1`。
- 动作是声明式文字模板。物品的持有者/可见性需要配置；不会执行导入配置中的 JavaScript。
- 历史与分支覆盖聊天正文、消息中的数据库帧及当前适配配置；不覆盖世界书、外部记忆、MVU、卡片级图片配置或其他插件，不是完整游戏回档。
- 目标楼层及此前出现多版本回复（swipe）时，工作台阻断对应状态与分支操作，避免把正文与未独立保存的表格状态配错。可从产生多版本之前的楼层创建新聊天分支。
- 群聊的分支与磁盘核对不支持；已有 MVU 卡不要把同一状态同时交给两个系统写入。
- 规则诊断不会自动修正数据，模型填表能力由数据库及角色卡配置决定。

## 更新、停用与回退

在酒馆「管理扩展」中检查并更新本扩展，完成后刷新页面。GitHub 上传新提交后，已安装实例不会凭空立即更新；本扩展未启用自动更新。

更新前使用酒馆与数据库各自的导出功能备份重要聊天/数据。停用工作台并刷新可恢复宿主界面；停用不删除数据库表格和聊天级配置。代码回退不会回退已发生的数据库变化。

若发布者提供旧版本分支或标签，可在支持选择分支/标签的宿主中选择对应版本；不要把提交 SHA 或 `URL#commit` 当作通用安装地址。普通仓库 URL 安装的是当时默认分支，依赖更新后应重新检查兼容性。

## 验证范围

当前基线：工作台 0.4.0，SillyTavern 1.19.0（`06bde939fb1e9c4c8d8641d810f0a916b5bce127`），shujuku（`0d9cc1a50417398f1e96834b6a3be684f94839f2`）。详细信息见 [compatibility.json](compatibility.json)。

118 项自动化测试和包检查通过。两套全新隔离酒馆从真实 GitHub 匿名安装，15 个服务资源与提交逐字节一致。旧版测试副本通过酒馆原生更新接口从 0.3.1 升级至 0.4.0，受控旧聊天、适配配置与数据库帧的宿主回读和磁盘字节保持一致；升级后浏览器实际打开聊天、读取库存并追加草稿，原文字保留、没有自动发送或扣库存。

本次公开安装后的实际浏览器补验通过：首次样例初始化；两人含图包预览、取消、确认合并；未保存简介的继续编辑和放弃；侧栏切人、详情立绘、刷新重开后图片恢复；普通第 0 楼历史分支。人物界面在 320×568、390×844、768×500 和 1440×900 做了基础检查，含窄屏滚动和低高度布局。这些是限定样例的验收，不是所有界面的完整尺寸矩阵。

长名单/长简介、切卡编辑竞态、部分成功故障提示和人物列表迟到更新仍未完成浏览器专项回归。手机硬件/软键盘、Tauri、真实模型驱动本扩展、长篇负载、复杂插件组合与 Plotti 存档闭环仍未验收。本版保持预览状态。

## 发布与开发

上传方法见 [发布说明](RELEASING.md)。**必须把本目录里的文件上传到仓库根目录**，让仓库首页直接看到 `manifest.json` 和 `index.js`，不要多包一层文件夹。安装不需要运行 npm 或构建命令。

开发检查（需 Node.js）：

```sh
npm test
npm run check-package
```

本包不包含数据库源码、构建产物、聊天记录、API 密钥或 Plotti 资产。界面交互参考叙事游玩界面的使用方式，非 Plotti 官方产品。

第三方来源：[SillyTavern](https://github.com/SillyTavern/SillyTavern)、[shujuku](https://github.com/AlbusKen/shujuku)。固定数据库版本未发现明确根目录许可文件，因此保持独立依赖，不随本包复制发布。本项目保留 Narrative Workbench 署名，由 hc568871650-commits 发布。目前未授予额外开源许可证；公开托管不等于授予任意再分发或修改许可。

安装机制参考：[SillyTavern 扩展文档](https://docs.sillytavern.app/extensions/)与[扩展开发文档](https://docs.sillytavern.app/for-contributors/writing-extensions/)。
